New in 0.15.5
• Faster AutoFill on sites with one saved login: when you tap PassAuth in the suggestions and only one login is saved for the page, it fills at once, without the list. You can turn this off in Settings → AutoFill: "Fill at once when one login matches".
• With "Suggest every login above the keyboard" on, each suggestion now shows the login's name next to the user name (for example "admin · Portainer"), so logins with the same user name on one domain are easy to tell apart.

Please test:
1. Open a sign-in page that has exactly one saved login, tap PassAuth in the suggestions: it should fill straight away.
2. Open a page with two saved logins: the list should appear as before.
3. Turn on "Suggest every login above the keyboard": suggestions should read "user · name".
