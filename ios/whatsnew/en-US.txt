New in 0.5.6
• Choose where a new passkey is saved. When a website asks to save a passkey, PassAuth now lists your logins for that exact site under "Save in", plus "New login". The matching login is picked for you, so you no longer get a second login for a site you already have.
• A passkey is never saved in a login for a different site that only shares the same main domain (for example cloudy.example.com and bazarr.example.com).
Please test: create a passkey on a site you already have a login for and check it is added to that login; then try a site with no login and check a new login is created.
