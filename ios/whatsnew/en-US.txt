New in 0.15.6
• Your logins are back above the keyboard: "Suggest every login above the keyboard" is now on by default, and each suggestion shows the login's name next to the user name (for example "admin · Portainer"), so you can pick the right one. If you turned this switch off yourself, it stays off. Settings → AutoFill.
• Tapping PassAuth in the suggestions still fills at once when only one login is saved for the page.

Please test:
1. Open the sign-in page of a site whose login is set to Host: the login should be suggested above the keyboard as "user · name".
2. Tap it: the right user name and password are filled.
