New in 0.15.3
• AutoFill picks the right login on sites that share a domain. Logins set to match by Host, Exact or Starts with, and logins that share a user name on one domain (for example "fahed" on cloud.example.com and media.example.com), no longer appear in the suggestion above the keyboard, where the system could offer the wrong one. Tap PassAuth there instead: its list shows the login for the page you're on first.
• Logins set to Base domain still appear above the keyboard as before.

Please test:
1. Have two logins on two sites of one domain (for example a.yourdomain.com and b.yourdomain.com), with the same user name or set to Host. On each sign-in page, open PassAuth from the suggestion bar: the right login should be at the top, and filling should use its password.
2. A login set to Base domain should still appear directly in the suggestion bar.
