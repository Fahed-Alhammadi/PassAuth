New in 0.15.2
• AutoFill no longer mixes up logins that share a user name on one domain. If you have, for example, two "fahed" logins on cloud.example.com and media.example.com, each is now suggested on its own site, so the keyboard's suggestion can't fill the other login's password.
• Buttons that remove something (Log out, Move to trash, Delete forever, Discard) now show their icon in red too.

Please test:
1. Save two logins with the same user name on two sites of one domain (for example a.yourdomain.com and b.yourdomain.com), both with the website match "Base domain". On each site's sign-in page, the suggestion above the keyboard should show that site's login, and filling should use its password.
2. Check the red icons on Log out (Settings → Account), Move to trash and Delete forever (a login in the trash), and Discard (editing a login).
