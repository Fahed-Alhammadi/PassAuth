New in 0.15.14
• AutoFill now also keeps services apart when they share one address on different ports (for example 192.168.1.10:7878 and 192.168.1.10:8989): iOS no longer suggests them above the keyboard. Tap "Passwords" → PassAuth, and the login for the page you're on is at the top.
• Logins that hold only a verification code follow the same rule, so a code isn't offered on the wrong service.

Please test:
1. Open a service on an address you use with several ports: no PassAuth suggestion above the keyboard. Tap "Passwords" → PassAuth: the page's own login is listed first, and filling it works.
2. On a site with a verification code saved, the code is offered only for that site.
3. A domain with a single login still has its one-tap suggestion.
