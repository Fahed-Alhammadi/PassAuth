New in 0.15.0
• Work offline: when your server can't be reached, you can still add items, edit them and move them to the trash. Changes show "Waiting to sync" and are sent by themselves when the connection comes back. Logins saved from AutoFill while offline wait too.
• If an item was changed on another device in the meantime, PassAuth asks you what to keep: Keep mine, Keep the other, or Keep both.
• Each item with a waiting change has "Discard this change". Logging out warns you first if changes haven't been sent.

Please test:
1. Turn on Airplane Mode. Add a login, edit another one and move a third to the trash. Check each shows "Waiting to sync".
2. Turn Airplane Mode off and open PassAuth. Check the changes reach the web vault.
3. Edit the same login offline on the iPhone and online in the web vault, then reconnect. Try each choice in the "Changed on another device" sheet.
