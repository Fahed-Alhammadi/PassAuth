Support

Help with PassAuth apps, the browser extension and the server.

Contact

Ask a question or report a problem on GitHub Issues. Please don't include passwords, codes or other vault contents in your report.

To report a security vulnerability privately, use Report a vulnerability on GitHub instead of a public issue.

Getting started

  • You need a PassAuth server. Run your own (see the installation guide) or ask the person who runs your organization's server for an account.
  • Connect an app or the extension by entering the server's address (it must start with https://), then sign in with your email and master password.
  • Turn on autofill on Android in the app's Settings → Autofill, which opens the system setting where you choose PassAuth.

I forgot my master password

Nobody can recover it, not even the server's administrator: your vault is encrypted with keys only your master password (and Secret Key, if you use one) can unlock. The account can only be deleted and created again. Write your master password down in your Emergency Kit and keep it somewhere safe.

I lost my Secret Key

Your Secret Key is in the Emergency Kit you saved when you created the account, and on every device where you've signed in. Without it you can't sign in on a new device.

Delete your account

Open your PassAuth server in a browser, sign in to the web vault, and go to Settings → Account → Delete account. This permanently deletes the account and all vaults you own. If you can't sign in, ask your server's administrator to delete it from the admin page. See also the privacy policy.

Running the server

Installation, the admin token, email, HTTPS, updates and backups are covered in the installation guide.
